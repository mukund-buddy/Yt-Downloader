        How it works
        
Three steps, no accounts.

        
TuneGrab is a small local app. Your browser talks to it on localhost, and it calls yt-dlp and ffmpeg on your machine.

      

      

        

          
Start the engine

          
Double-click start.bat. The first run installs yt-dlp if it is missing, then opens this page at 127.0.0.1:8787.

        

        

          
Paste links

          
A playlist URL, a single song, or a whole list of links — one per line. Pick audio or video, quality, and any extra words for the filename.

        

        

          
Download

          
Progress appears live, item by item. Files land in your chosen folder with clean tags, fixed dates, and the names you asked for.

        

      

    

  


  
  

    

      

        Features
        
Everything a music folder needs.

        
Built around the small details that make a library pleasant to keep: predictable names, clean tags, and no surprises.

      

      

        

          

          
Playlists and singles

          
Paste a playlist and every track is expanded and queued. Paste a song link and it downloads alone. Mix both in one job.

        

        

          

          
Audio or video

          
MP3 from 128 to 320 kbps, or MP4 video from 360p to 4K. One switch decides the whole job.

        

        

          

          
Quality you choose

          
No guessing. Pick the exact bitrate or resolution; TuneGrab asks yt-dlp for the best stream within that limit.

        

        

          

          
Your words in the name

          
Add a prefix, a suffix, or a full yt-dlp template. Old Hindi Artist - Song slowed + reverb.mp3 is a real example.

        

        

          

          
Clean metadata

          
Tags are stripped to title and artist only. Cover art, comments, dates, encoder notes and chapters are removed, and file dates are fixed.

        

        

          

          
Agent control

          
A JSON API, an SSE progress stream, and a one-shot CLI with JSON events. Your agent can run a full playlist and report back.

        Setup
        
Two ways to run it.

        
Double-click for normal use. Command line when an agent is driving.

      

      

        

          Recommended
          
Double-click start.bat

          
Works on Windows with Python installed. The script checks yt-dlp, starts the engine, and opens the app in your browser.

          
    
            
  1. Keep the folder anywhere you like.
    2. 
            
  2. Double-click start.bat.

    4.

Needs python and ffmpeg on PATH. yt-dlp is installed automatically if missing.

Run from the terminal

          
Start the server once, then let the agent post jobs or call the one-shot command directly.

python bridge\tunegrab_bridge.py add "URL" \
  --mode video --quality 1080 --json

        FAQ
        
Good questions.

      

      

        

          Does it need an account or a cloud server?
          
No. Everything runs on your machine. The browser page is served by the local engine, and downloads go straight to your folder.

        

        

          What exactly is removed from the files?
          
With clean metadata on, ffmpeg rewrites the file with -map_metadata -1, then writes only title and artist. Cover art and chapters are dropped, and the file date is set to 2000-01-01.

        

        

          Can it download a whole playlist in one go?
          
Yes. Paste the playlist URL. TuneGrab resolves every item first, shows the total, then downloads one by one. Use Max items to cap it.

        

        

          How do I add my own words to the filename?
          
Use the two word fields, or write a full yt-dlp template such as %(artist,uploader,channel)s - %(title)s. The preview under the fields updates as you type.

        

        

          Is a private or age-restricted video supported?
          
Export cookies from your browser in Netscape format and point the cookies field at the file. TuneGrab passes it to yt-dlp.

        

        

          Where do the files go by default?
          
To %USERPROFILE%\Music\TuneGrab. Change the save folder in advanced options; the choice is remembered in your browser.
